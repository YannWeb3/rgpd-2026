✅ 4. Checklist d'audit pour l'externe

Cohérence visuelle

  • Tous les outils ont-ils le même design sombre (fond #0b0f19, cartes #161b26) ?
  • Les formulaires (page d'accueil) ont-ils un design différent (clair, bleu UNAPEI) — est-ce intentionnel ?
  • Les icônes sont cohérentes (emojis partout) ?
  • Les typographies sont uniformes (Inter) ?
  • Les couleurs des tags sont cohérentes entre les pages ?

Cohérence des liens

  • Tous les liens internes renvoient 200 (vérifié ✅ — 36/36)
  • Aucun lien ne pointe vers un fichier supprimé (ex : Kit_de_formations.html, UNAPEI92_RGPD_3approches.md)
  • Le lien « Retour à la boîte à outils » est présent sur toutes les pages sauf la boîte à outils elle-même ?
  • Les 3 pages orphelles (kit_formations, avancement, bilan-alten) ont-elles besoin d'un lien retour ?

Cohérence du contenu

  • Vérifier les 6 redondances listées ci-dessus (R1 à R6)
  • Les 8 rapports d'audit ont-ils la même structure (même H1 « Audit RGPD — vue globale ») ?
  • Les 16 formulaires ont-ils tous le même format et les mêmes champs de base ?
  • Les scores RGPD sont-ils calculés de la même façon entre les rapports et le dashboard premium ?

Accessibilité

  • La page login.html redirige-t-elle correctement après connexion ?
  • La page admin.html est-elle protégée (mot de passe, code établissement) ?
  • Les formulaires sont-ils accessibles sans login (lien envoyé aux personnes) ?
  • La boîte à outils est-elle accessible publiquement ou restreinte ?

RGPD de la boîte à outils elle-même

  • Les formulaires envoient-ils les données vers Google Sheets (Apps Script) ?
  • Y a-t-il une mention d'information sur le traitement des données (article 13 RGPD) ?
  • Les réponses aux formulaires sont-elles anonymisées ou nominatives ?
  • Qui a accès aux données collectées (Google Sheet partagé) ?
